# README screenshots

These are curated documentation assets, captured from the running application on
2026-09-14 at a 1440 × 1000 desktop viewport, then compressed to WebP.

- `galaxy.webp`: the public interactive memory galaxy.
- `admin.webp`: the owner dashboard with authored demo memories.
- `settings.webp`: the saved Site settings, including search identity.

The screenshots use a separate local PostgreSQL database, demo@example.com, and
fictional example memories. They contain no production records. The original PNG
captures and browser logs remain ignored under `output/playwright/`; only these
reviewed documentation images are committed. Screenshots show the project's existing
visual assets and do not change their licensing.
